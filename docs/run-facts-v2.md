# Pure in-progress run facts v2

`src/server/github-run-facts-v2.mjs` exports `decodeGitHubInProgressRunFactsV2(rawJson, endpoint)` and `assertGitHubInProgressRunFactsV2(actual, expected, pathPolicy)`. Adjacent `.d.mts` declares `RunNumericIdentityV2`, `InProgressRunFactsV2` and `RunTargetV2`. This implements the [accepted parent contract](../../docs/architecture-source-run-v2-proposal.md), assigned locally by Lead on 2026-10-16.

Decode produces exactly nine own fields: local `schema_version: 2`, caller-supplied `endpoint: run|attempt`, `identity`, unchanged upstream path as `raw_path`, `head_sha`, `head_branch`, `event`, `status`, and `conclusion`. Identity has exactly five canonical decimal strings: `id`, `run_attempt`, `workflow_id`, `repository_id`, `head_repository_id`. Number tokens remain lossless, with 20-digit IDs and 10-digit attempts. No provider metadata can override the local schema/endpoint or projected fields. Endpoint is context, not proof of origin.

One call to the existing [bounded parser](source-identity-decoder.md) performs iterative preflight then one pinned lossless dependency parse. Required upstream fields are own data properties, including a present JSON-null conclusion. The decoder requires lowercase 40-hex SHA, branch `main`, event `push|schedule|workflow_dispatch`, status `in_progress`, and conclusion `null`. Bounded unexpected/empty paths may decode; they fail subsequent policy comparison. No path stripping, normalization or legacy decoder call occurs.

Comparison snapshots exact own enumerable data descriptors on plain/null-prototype actual/target objects and nested identities, checks fixed facts and canonical strings, and enforces same-repository identity on the expected target only. It then calls [path-v2](workflow-path-v2.md), preserving its complete constructed-path limit and invalid-before-mismatch ordering, before comparing identity/event. A different actual repository is a mismatch against a valid same-repository target. Success returns void and indicates only equality with supplied inputs.

Both functions use redacted `invalid_github_in_progress_run_facts_v2` for malformed input, unsupported lifecycle, resource/duplicate failures or invalid policy. Valid path/SHA/identity/event differences produce `github_in_progress_run_facts_v2_mismatch`. Neither retains raw input, inner error/cause or partial output.

`github-run-facts-v2-internal.mjs` holds the projection/validation and an internal dependency-parser seam. Preflight always runs before that seam; the public decoder has no parser override. Tests exercise the actual public decoder/comparator, all three path forms, A/attempt/B against one target/policy, adjacent unsafe numeric IDs, own-null/missing fields, escaped duplicates, metadata injection, descriptor safety, redacted error precedence, and exact resource boundaries. The internal seam asserts one dependency parse for valid input and zero on preflight rejection.

Fixtures are synthetic; in-progress/same-repository assumptions are not authenticated observations. Legacy decoder/path-v2 implementation and suites remain unchanged, with no new dependency or browser/vendor API. No configuration enrollment, observer, network, filesystem, clock, database, receipt, claim or deployment authority is implemented. Provider origin, compatibility, freshness and source admission remain separately gated.
